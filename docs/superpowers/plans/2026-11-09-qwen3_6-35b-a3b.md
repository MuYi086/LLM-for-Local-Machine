# Qwen3.6-35B-A3B-MTP Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans` to implement task-by-task. Follow each RED-GREEN cycle and record evidence in the SDD ledger.

**Goal:** Expose the local Qwen3.6-35B-A3B-UD-Q5_K_M model through the exact API in `task4.md` on port 8402, managed by `start.sh`, and generate a real sample.

**Architecture:** Reuse the existing parameterized llama.cpp FastAPI adapter and runtime lifecycle. Keep the Ornith public API on 8401 and move its backend to 8403; bind Qwen API on 8402 and its backend on loopback alias `127.0.0.2:8400` to coexist with LocalAI at `127.0.0.1:8400`. Each model has its own llama-server process; all backend startup, inference, and shutdown share the same GPU lock and quarantine protocol.

**Tech Stack:** Python 3.12.13, FastAPI, HTTPX, llama.cpp `llama-server`, Bash, unittest, uv.

**Spec:** `docs/superpowers/specs/2026-11-09-qwen3_6-35b-a3b-design.md`

## Global Constraints

- Keep the GGUF at `$HF_MIRROR_DIR/unsloth/Qwen3.6-35B-A3B-MTP/Qwen3.6-35B-A3B-UD-Q5_K_M.gguf`; do not download, move, or commit weights.
- Public routes are Ornith `8401` and Qwen `8402`; Ornith backend is `127.0.0.1:8403`; Qwen backend is loopback `127.0.0.2:8400`; LocalAI remains `127.0.0.1:8400`.
- Qwen llama.cpp defaults are CUDA0, 99 GPU layers, 25 CPU MoE layers, `draft-mtp`, 32768 context, batch size 512, parallel 1, Flash Attention, Jinja, and 1-second sleep-idle.
- Every Qwen and Ornith GPU operation uses the same positive-timeout `GPU_LOCK_FILE`; any unconfirmed backend shutdown leaves quarantine in place.
- Generated text stays under `storage/llm_tests/qwen3_6_35b_a3b/`; mock tests never load a model or require CUDA.

## Review Focus

- Port overlap: Qwen API 8402 must not collide with either llama-server; test all defaults and the LocalAI loopback alias.
- Partial startup: failure to start either backend must stop every earlier backend and API process group without leaving a stale PID or clearing an unsafe quarantine.
- Request isolation: Qwen and Ornith aliases, route paths, backend hosts, and markers must not cross; exercise shared GPU lock and stream cleanup.
- Model MTP handling: require `--spec-type` support and pass `draft-mtp`; validate the exact local model before starting services.
- Short completions: sample generation disables thinking in its own request and rejects empty assistant content.
