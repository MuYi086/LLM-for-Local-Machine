# 本地模型性能记录实施计划

目标：默认记录 Qwen/Ornith 请求阶段、资源采样及可核查的性能汇总，配置 false 可关闭。

架构：标准库共享模块提供 ASGI 旁路观测、JSONL 写入和资源采样；start.sh 管理采样生命周期。离线 CLI 按时间范围汇总，原始日志与报告分开保存，不覆盖历史测试结果。

约束：不记录请求/回答正文或凭据；不改变 GPU 锁、quarantine 和已收到的流式响应字节（启用记录时可补 include_usage，尊重显式 false）；不下载模型、不运行真实推理；保留当前未提交改动。不将网关延迟当客户端 TTFT，不将服务时间窗口当精确 OpenCode 任务。

1. 为关闭开关、分块 SSE、工具调用、异常、写入失败和资源缺失编写无模型测试，观察失败。
2. 实现共享 telemetry 模块及请求观测；在网关与文本适配器接入 ID 和阶段标记。
3. 实现资源采样及离线汇总 CLI；接入 start.sh 默认配置、启动与退出管理；补充测试。
4. 文档说明配置、分次测试起止标记、汇总命令及 WSL/采样峰值限制；执行质量门禁和代码审查。

取舍：持续采集作为基础，agent 只做分析；不靠 agent 自己监控。OpenCode 客户端事件没有现有接入，界面统计、自动压缩和工具耗时仍须客户端导出或手动补录。


实施记录：以上四项已实现。独立只读审查未发现 Critical/Important；审查指出的基线计入峰值问题已由失败回归测试复现并修复，窗口外基线不参与峰值计算。新增无模型覆盖关闭开关、分块 SSE、工具/推理事件、取消、磁盘失败、超大整数、基线缺失、未结束请求、CLI begin/end 和启动退出。保持用户现有修改，不提交或重启运行中的服务。

补充验证：helper 退出导致 backend 脱离启动树的场景已用临时 PID 文件及独立 sleep 替身复现并修复；采样按 PID 文件加可执行文件校验追踪后端，仍记录 starttime 区分进程实例。性能专项 15 项、网关 13 项、Qwen 服务 4 项通过；最终门禁结果以实际运行输出为准。


后续需求：固定提示词 v3 明确本轮目录/ID、阶段快照和任务后离线收尾；新增 report/end --attach-result，以匹配测试 ID 的唯一标记原子更新本轮结果，保留审查正文。缺少显式目录、错误 ID、重复/缺失标记或符号链接目标拒绝更新。任务进行时不自行 end，不声称覆盖最终回复；最终 UI 统计仍待客户端提供。新测试覆盖原文保留、错误标记拒绝与 CLI 快照→结束窗口更新。

归档审查修正：独立审查发现 report 先截取快照、并发 end 后再次读取状态会误标 ended；已用失败测试复现，改为首次观测同时固定 window_end/test_state。另保留块外 CRLF 字节并覆盖失败原子替换回滚。性能专项 22 项通过。


OpenCode 压缩修复：通过只读会话数据库确认四次无分页 read 导致 2556 行一次返回，随后摘要模板校验失败；增加仓库 V2 插件分离压缩 system、关闭仅摘要 thinking、限制源码 read，精简为 v4 提示词。保留 32K 和自动压缩配置。通过 Node 单元及隔离 OpenCode/假模型的真实执行链验证，不调用真实 GPU 模型。
