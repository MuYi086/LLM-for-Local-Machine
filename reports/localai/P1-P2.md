## 当前实现

- LocalAI 管理器核验宿主机二进制版本、backend 入口、backend 整树 SHA-256、路径边界及 loopback API 状态。
- LocalAI 与可选 gRPC worker bridge 由宿主机进程组管理；启动等待 readiness，停止采用有界 TERM/KILL，
  并检查进程组和监听端口后再清理状态。owner watcher 负责处理启动 shell 异常退出。
- Qwen3-TTS Base 克隆和 VoiceDesign 保留独立的直接 LocalAI 候选；Base 默认 native，VoiceDesign 固定使用 audio.cpp GGUF。
- TIGER-DnR 保留一个固定 one-shot worker bridge。
- 所有 LocalAI 请求与 native worker 共用 GPU 锁；backend shutdown 无法确认时保留 quarantine 标记。
- 镜像内没有的模型及必需辅助权重对应服务已退役；缺失 GGUF 的四个 LocalAI 直连候选已删除，
  对应镜像模型仍存在的 native 服务继续保留。
