## 已实现

- 新增轻量 `inference_gateway` 包，使用标准库和 `unitale_runtime`，不导入 FastAPI、Torch 或模型包。
- 配置默认关闭 LocalAI，provider 只接受 `native` / `localai`，地址只允许本机 HTTP 回环；连接、请求、清理和 GPU 排队都校验有限正数超时。
- LocalAI ASR 上传使用固定长度 multipart 流式 body，按 1 MiB 分块发送；响应限于 16 MiB，并保留 API 层计算的上传 SHA-256、大小与后缀。
- multipart 文件名先限制为 255 字符的安全 ASCII 参数；含控制字符或非 ASCII 的 Content-Type 在发请求前拒绝，避免客户端元数据破坏 multipart 头边界。
- Qwen3-ASR LocalAI 路径不检查 `qwen-asr`、Torch 或原生 HF 权重；`context` 非空和非默认 `max_new_tokens` 显式返回 422。
- LocalAI 请求持有共享 `GPU_LOCK_FILE`，随后调用 `/backend/shutdown`。请求期间创建原子隔离标记，LocalAI backend 停止失败或服务进程崩溃时保留标记。
- `unitale_runtime.gpu_runtime_lock` 获得文件锁后检查隔离标记，标记存在时拒绝 GPU 准入；该检查覆盖共享该运行时的原生模型服务。
- 新增 `scripts/localai/preflight.py` 和 `recover_quarantine.py`。显式 LocalAI ASR 启动时检查实例和模型注册；恢复脚本持 GPU 锁并在 LocalAI 确认模型停止后清除隔离标记。
- `scripts/localai/manager.py` 已改为校验宿主机 LocalAI `v4.11.0` 二进制与 audio-cpp backend 整树文件指纹，
  以独立进程组启动本机 `local-ai run`，只监听 loopback、限制一个活动 backend、关闭 gallery 自动加载/API 与 WebUI，
  等待 `/readyz` 后返回。`start.sh` 可选托管并启动 owner watcher；回收通过 PID 启动 tick、运行标识、TERM/KILL、
  进程组扫描及端口关闭确认完成。相关环境字段仍以固定版本 [`run.go`](https://raw.githubusercontent.com/mudler/LocalAI/v4.11.0/core/cli/run.go)
  为依据；二进制、backend 和进程行为未实测。
- 新增 Qwen3-ASR 候选注册与预检：核对固定 HF 包路径、文件长度与 SHA-256，原子写入匹配的 YAML；显式 LocalAI
  provider 启动前再次逐块校验制品和配置。候选路径现与 HF 固定 revision 中的文件名一致，但文件仍未下载。
- 受管 LocalAI API 不可用时，quarantine 恢复路径持有 GPU 锁，停止并确认宿主机进程组退出、状态文件消失且 API 端口关闭后，
  才清除隔离标记；非托管模式仍要求 LocalAI API 确认 shutdown。
- P1 生命周期决策记录见 [`P1-lifecycle-decision.md`](P1-lifecycle-decision.md)：当前先验证原生 audio-cpp backend 的
  `/backend/shutdown`，不提前增加 gRPC adapter；如果固定宿主机 backend 未能确认退出，再实施一次性子进程 adapter。
- `start.sh` 默认关闭 LocalAI，提供共享 `PYTHONPATH` 兜底；质量门禁和 Qwen3-ASR uv 锁包含新包。
- Qwen `/v1/health` 增加当前 provider 与所选 provider 可用性。原有 worker 和依赖保持不变。

## 字段与限制

| 当前 ASR 字段 | 当前实现 | 状态 |
| --- | --- | --- |
| `audio` | multipart `file`，分块上传 | 代码与本机 HTTP mock 已覆盖；固定 LocalAI 未验证 |
| `language` | 作为 multipart `language` 原值传递 | 需核对固定模型参数格式；自动识别时要求响应带 `language` |
| `context` | 非空时返回 422 | audio.cpp LocalAI 转写路径尚无已验证的 context 字段映射 |
| `max_new_tokens` | 非默认值返回 422；默认行为仍走模型配置默认值 | native 默认值与 audio.cpp 默认值尚未证明等价 |
| `elapsed_seconds` | 用 LocalAI 请求墙钟时间填充 | LocalAI 冷加载和推理计时语义仍需真实请求核对 |
| `audio.sha256/size_bytes/suffix` | 使用既有上传 staging 元数据生成 | 不信任 LocalAI 返回的文件名或摘要 |

尚未接入标准 LocalAI transcription 请求没有列明的 Qwen3-ASR 上下文和 token 参数；不得把当前 ASR
provider 标成已完成或切换默认值。LocalAI 版本化请求扩展/专用 backend 是后续决策项。
