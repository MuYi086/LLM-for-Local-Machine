请用 HTML 实现一个可直接在浏览器打开的「周末城市微旅行规划器」单页网页，并且只输出完整 HTML 源码，不要 Markdown 代码围栏或说明文字。

具体要求：
1. 所有 CSS 和 JavaScript 都写在同一个 HTML 文件中，不加载外部字体、图片、脚本、框架或网络资源；页面离线也能使用。
2. 使用简体中文，视觉清爽、有明确层次，适配桌面和手机屏幕。
3. 顶部展示标题、简短说明和一个醒目的本周末日期标签。
4. 提供目的地输入框和人均预算输入框；修改预算后，预算进度和剩余预算即时更新。
5. 展示至少三条周末行程卡片，每条包含时间、地点、活动说明和费用；每条卡片都能勾选「已完成」，并有添加行程和删除行程的交互。
6. 展示一个可交互的行李清单，至少包含相机、充电器、雨伞三项；勾选状态可切换。
7. 初始内容要真实、完整且适合一次轻松的周末短途旅行；主要按钮和交互都必须能工作。
8. 用语义化 HTML，提供基本键盘焦点样式；JavaScript 使用原生 API，不依赖第三方库。

请确保 HTML 标签完整闭合，并在文档末尾输出 </html>。
