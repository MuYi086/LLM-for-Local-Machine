# Index 原生接口的环境准备

当前 Demo 直接调用 8382–8385 四个原生接口，Echo 保存 WAV，其余保存 TXT。
运行状态和跳过原因见 [环境检查报告](../../环境检查报告.md)，请求字段见
[根目录接口文档](../../README.md#index-echo-原生语音翻译)。Demo 使用 Python 标准库，无需
额外安装 OpenAI 客户端，也无需手动维护独立 8000 端口或外部文本推理源码。

## Echo 原生语音服务

8382 需要完整 [Index-Echo-S2ST-9B 官方包](https://huggingface.co/IndexTeam/Index-Echo-S2ST-9B)，
默认目录为 `$HF_MIRROR_DIR/IndexTeam/Index-Echo-S2ST-9B`，其中必须有 `modeling_dubbing.py`、
STLM、mapper、CosyVoice3 和配套代码/资源。只有文本 GGUF 无法运行此原生服务。
官方要求 CUDA 单卡至少 24 GB；本机 16 GB，按用户要求跳过，不为了本机下载完整包。

满足条件的主机执行：

```bash
uv sync --project Index-Echo-S2ST-9B-GGUF --locked --extra native
export HF_MIRROR_DIR="${HF_MIRROR_DIR:-$HOME/hf-mirror}"
export INDEX_ECHO_S2ST_MODEL_DIR="$HF_MIRROR_DIR/IndexTeam/Index-Echo-S2ST-9B"
uv run --no-sync --project Index-Echo-S2ST-9B-GGUF python Index-Echo-S2ST-9B-GGUF/main.py
```

`native` extra 已锁定官方测试版本，Torch/Torchaudio 来自 CUDA 12.9 wheel 源；不带 extra
只准备轻量 HTTP 环境。服务 `GET /v1/health` 会报告原生包、依赖版本、FFmpeg 和 GPU 条件。

## 三个文本服务

已有 Q8_0 权重分别位于 `$HF_MIRROR_DIR/IndexTeam/Index-Homura-9B-GGUF/`、
`Index-Nailong-9B-GGUF/`、`Index-Translate-9B-GGUF/`；无需重复下载。
准备支持 Qwen3.5 的 [llama.cpp](https://github.com/ggml-org/llama.cpp) `llama-server`，
安装在 PATH 中或设置各自 `*_LLAMA_SERVER_BIN`。模型只在请求 worker 中运行，默认每次
独占共享 GPU 锁，不常驻三个模型，也不调用 ASR/TTS。

```bash
uv sync --project Index-Homura-9B-GGUF --locked
uv sync --project Index-Nailong-9B-GGUF --locked
uv sync --project Index-Translate-9B-GGUF --locked
```

Homura 与 Index-Translate 默认上下文 32768；Nailong 按官方 9B 预设使用 229376。
长上下文需要更多 KV cache 显存；可显式配置 `INDEX_HOMURA_CONTEXT_SIZE`、
`INDEX_NAILONG_CONTEXT_SIZE`、`INDEX_TRANSLATE_CONTEXT_SIZE`。接口不会自动缩短原文或分段替代
NativeLong 整篇翻译。Nailong 使用仓库内按官方固定模板实现的提示词，不依赖额外下载模板。

图片翻译另需 [官方 mmproj 文件](https://huggingface.co/IndexTeam/Index-Translate-9B-GGUF)，
默认 `Index-Translate-9B.mmproj-Q8_0.gguf` 位于 Index-Translate 模型目录；可用
`INDEX_TRANSLATE_MMPROJ_PATH` 指定。`image_ready` 与文本 `ready` 分别报告，缺失组件不会被
外部 OCR 或其他模型替代。

## 启动与检查

统一使用 `bash start.sh`，也可在对应服务目录独立启动。修改已运行的接口后，先 Ctrl+C
等待旧进程组退出，再重新启动；旧 Python 进程中的路由不会自动更新。

```bash
python3 tests/testIndexEchoS2ST/demo.py --check-only
python3 tests/testIndexHomura/demo.py --check-only
python3 tests/testIndexNailong/demo.py --check-only
python3 tests/testIndexTranslate/demo.py --check-only
```

检查通过后去掉 `--check-only`，输出写入各自 `dist/`。文本 Demo 可传 `--base-url`、
`--input`、`--output` 和模型对应参数；Index-Translate 可传 `--image screenshot.png`。
Echo `--return-info` 保存 ZIP，包含原生 WAV 和原生诊断信息。
